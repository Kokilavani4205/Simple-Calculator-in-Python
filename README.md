# 🧮 Simple Calculator in Python

## 📌 Project Overview
The Simple Calculator is a beginner-friendly Python application that performs basic arithmetic operations. It takes input from the user and displays the calculated result.

## ✨ Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Input validation
- Division-by-zero error handling

## 🛠️ Technologies Used
- Python 3
- Visual Studio Code (VS Code)

## 📂 Project Structure

```text
Calculator/
├── calculator.py
└── README.md
```

## ⚙️ Requirements
- Python 3 installed on your computer.
- VS Code or another Python editor.

## 🚀 How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python calculator.py
```

On Windows, you can also use:

```bash
py calculator.py
```

## 💻 Sample Output

```text
===== SIMPLE CALCULATOR =====
Enter first number: 10
Enter operator (+, -, *, /): +
Enter second number: 5
Result: 15.0
```
